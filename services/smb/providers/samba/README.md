# SMB provider: samba (default)

**Provider id:** `samba`  
**Select:** `AMBER_SMB_PROVIDER=samba`

Classic Samba file server (`public` + `admin` shares).

## Alternates

| Provider | Honest label |
| --- | --- |
| `samba-ad` | Samba AD DC provision (lab) / AD-lookalike fallback |
| `samba-shares` | Multi-share file server layout |
