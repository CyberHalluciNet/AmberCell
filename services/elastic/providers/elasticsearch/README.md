# Elastic provider: elasticsearch

**Provider id:** `elasticsearch`  
**Select:** `AMBER_ELASTIC_PROVIDER=elasticsearch`

## License

Official Elasticsearch images use the **Elastic License / SSPL** family (not OSI Apache-2.0). Prefer `opensearch` or `zincsearch` when license posture requires it. This provider is shipped for protocol fidelity; note in NOTICE when present.
